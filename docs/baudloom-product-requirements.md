# Baudloom 产品范围与后续计划

Baudloom 面向嵌入式开发中的串口观察、命令调试和会话复盘。Windows 优先，离线使用，无账号或日志上传要求。

## 当前范围

0.1.2 的已实现功能以 [README](../README.md) 为准：单端口、UTF-8/HEX、自动校验、定时发送、可调整布局、有界缓存、显式保存与原始缓存补写、会话只读重开。

## 必须保持的行为

- 不自动打开实体串口。发送请求绑定明确的端口与连接身份，切换设备不能误发旧命令。
- 默认不保存会话。连接中启用保存补写仍保留的原始事件，明确提示已经淘汰的范围；补写不能重新执行命令。
- 清屏、暂停和筛选仅影响显示。原始记录和缓存独立于显示编码及列布局。
- 发送成功表示主机写入完成，不推断设备业务成功。定时任务可停止，断开与故障不自动续发。
- 写盘错误、容量限制和恢复缺口必须可见，不把部分记录描述为完整记录。
- 配置和持久数据默认归入 EXE 同级 `Baudloom-data`；用户显式选择的记录目录可沿用。
- 样例与公开测试使用合成数据，真实业务日志不进入仓库。

## 后续候选

以下项目尚未实现，顺序以实际反馈和验证结果为准，不承诺交付日期。

| 方向 | 内容 |
|---|---|
| 串口配置 | 数据位、校验位、停止位、流控及 DTR/RTS |
| 稳定性 | Windows 实体设备、拔插、慢盘、高 DPI 和长时间负载验收 |
| 日志与文件 | 分段记录、完整历史分页、TXT/LOG 导入、明确范围的导出 |
| 多设备 | 多端口独立采集、明确目标切换、有歧义时不自动重连 |
| 阅读与命令 | GB18030、书签管理、命令组导入导出、受限正则搜索 |
| 桌面体验 | 托盘后台采集、主题、快捷键完善 |

当前保留 Electron 技术栈；原生重写不属于本版本发布范围。验证原则见[测试计划](baudloom-test-plan.md)。
