# Baudloom 应用图标

本项目原创几何图形：两条交错的数据路径组成字母 B，表示 Baud 与 Loom；未使用外部品牌图标、图库或字体轮廓。保留源稿便于后续修改，不将原创绘制等同于全球商标或外观唯一性审查。

- `baudloom.svg`：唯一设计源，透明外缘、深灰底、白色与浅灰数据路径。
- `baudloom.png`：512 × 512，窗口与 Linux 应用使用。
- `baudloom.ico`：包含 16、24、32、48、64、128、256 像素，Windows EXE 与便携启动器使用。

修改 SVG 后在仓库根目录执行 `npm run icons`。渲染器为固定版本的 `@resvg/resvg-js`，仅构建依赖，不进入应用运行依赖。原创图标与项目代码均采用 [MIT 许可证](../../LICENSE)。
